# Роман Минин — «Внимание для художника» (Официальный промо-сайт)

Интерактивный промо-сайт книги Романа Минина в стилистике трансмонументализма и нео-витража.

## Структура сайта
1. **Hero-панорама с архетипом шахтёра:** Сгенерированный референс витражного графа в шахте с интерактивными точками перехода.
2. **Интерактивный Крест 4-х Валют (Глава 23):** Динамический компас (*Уважение, Любовь, Деньги, Внимание*) с цитатами Романа.
3. **5 интерактивных промо-квестов:** Пошаговые сценарии выбора (*«Конструктор удачи»*, *«Ровные очки»*, *«Предохранитель Куколки»*, *«Идея vs Желание»*, *«Крест Валют»*) с выдачей витражных артефактов.
4. **Интерактивный каталог 30 глав:** Живой поиск и фильтрация по 4 слоям с аутентичными цитатами и когнитивными параллелями.
5. **Блок об авторе и трансмонументализме:** Манифест *«Не бить зрителя ниже пояса»* и форма предзаказа книги.

## Локальный запуск
```bash
# Вариант 1 (Python)
cd sites/minin_attention_book
python3 -m http.server 3000

# Вариант 2 (Node)
npx serve sites/minin_attention_book
```

## Деплой на Render.com
1. Создайте **Static Site** на Render.com.
2. Укажите репозиторий проекта.
3. **Publish Directory:** `sites/minin_attention_book` (или корень, если вынесен в отдельный репозиторий).
4. **Build Command:** оставить пустым (чистый статичный стек без сборщиков).
